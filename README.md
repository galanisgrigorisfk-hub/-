# Εβδομαδιαίο Πρόγραμμα σε Python

Ένα απλό, διαδραστικό πρόγραμμα γραμμένο σε **Python** για τη διαχείριση του εβδομαδιαίου ωρολογίου προγράμματος. Σχεδιασμένο ειδικά για να διευκολύνει την καταχώριση, την οργάνωση και την αναζήτηση μαθημάτων, με πλήρη υποστήριξη της ελληνικής γλώσσας (χωρίς άγχος για τόνους!).

---

## Κύρια Χαρακτηριστικά

* Αυτόματη Αποθήκευση (JSON): Το πρόγραμμα αποθηκεύει αυτόματα τις αλλαγές σας σε αρχείο τοπικά, ώστε να μην χάνονται τα δεδομένα όταν κλείνει η εφαρμογή.
* έξυπνη Αναγνώριση Ημερών: Δεν χρειάζεται να προσέχετε τους τόνους ή τα κεφαλαία γράμματα κατά την πληκτρολόγηση των ημερών ή την αναζήτηση.
* Έξυπνη Μορφοποίηση Ώρας: Μπορείτε να πληκτρολογήσετε απλώς έναν αριθμό (π.χ. `9`) και το πρόγραμμα τον μετατρέπει αυτόματα σε `09:00`, με αυστηρό έλεγχο εγκυρότητας.
* Λεπτομερή Στοιχεία Μαθήματος: Υποστήριξη για Ώρα Έναρξης, Ώρα Λήξης, Όνομα Μαθήματος και προαιρετικό **Σχόλιο / Σημείωση** (π.χ. Αίθουσα, καθηγητής).
* Αναζήτηση στην Εβδομάδα: Μπορείτε να αναζητήσετε οποιοδήποτε μάθημα ανά πάσα στιγμή και να δείτε σε ποιες μέρες και ώρες πραγματοποιείται.
